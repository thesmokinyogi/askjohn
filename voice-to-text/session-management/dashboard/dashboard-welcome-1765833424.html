Voice-to-Text Transcription Service

A simple, modular web application for transcribing audio files using Google Speech-to-Text API.

Features

  • 🎙️ Web UI - Beautiful drag-and-drop interface
  • 🧠 Yoga-optimized - Custom vocabulary for yoga terminology
  • ⚡ Fast - Results in seconds
  • 🔧 Modular - Easy to swap STT providers (Google → Whisper)
  • 🎯 Accurate - Word-level timestamps and confidence scores

    • Quick Start

    👉 [See SETUP.md for complete installation instructions](./SETUP.md)

    Short version:

    1. Install dependencies
    
python3 -m venv venv
    source venv/bin/activate
    pip install -r requirements.txt
    2. Configure Google Cloud credentials (see SETUP.md)
    
cp .env.example .env

    Edit .env with your credentials path
    3. Run the server
    
python -m app.main
    4. Open browser
    
open http://localhost:8000

    Session Management Commands
    ./hi or ./wake.sh
    Purpose: Start a new COGSPACE session
    What it does:
    • Restores cognitive context from previous session (90%+ continuity)
    • Checks for COGSPACE version upgrades and auto-heals if needed
    • Prompts for GitHub auto-sync setup (first time only)
    • Auto-pulls latest changes from GitHub (if auto-sync enabled)
    • Generates and opens interactive dashboard
    • Displays work narrative, goals, and next actions from last session
    ./save or ./save.sh "checkpoint message"
    Purpose: Save progress mid-session (crash protection)
    What it does:
    • Saves complete cognitive context without ending session
    • Creates backup of current work state
    • Does NOT commit to git or close session
    • Use this frequently for important milestones
    ./bye or ./sleep.sh "session summary"
    Purpose: End session and preserve complete workspace state
    What it does:
    • Saves complete cognitive context with AI-generated summaries
    • Generates executable next-actions script for next session
    • Auto-commits all changes to git (if auto-sync enabled)
    • Auto-pushes to GitHub for cloud backup (if auto-sync enabled)
    • Closes dashboard
    • Creates portable context for session continuity

    🗄️ Database Architecture
    ⚠️ IMPORTANT: Two Database Locations

    COGSPACE has separate locations for database utilities vs. data. Don't confuse them!

    Location Purpose Contents
    cogspace/db/ Utilities & Schema Python manager, schema.sql, helper code
    .cogspace/cogspace.db Runtime Session Data Actual sessions, memories, context (SQLite)
    Project Structure:
    my-project/
    ├── .cogspace/
    │ └── cogspace.db ← ACTUAL SESSION DATA
    ├── cogspace/
    │ └── db/
    │ ├── cogspace_db.py ← Utilities
    │ └── schema.sql ← Schema definitions
    Query Session Data:
    # Find the database
    ls -la .cogspace/cogspace.db

    # Query recent sessions
    sqlite3 .cogspace/cogspace.db "SELECT id, created_at, score FROM sessions ORDER BY created_at DESC LIMIT 5"
    💡 Why This Architecture?
    • Separation: Code (cogspace/db/) vs. Data (.cogspace/)
    • Git-friendly: .cogspace/ is gitignored; session data stays local
    • DNA-safe: Code syncs from DNA; runtime data is preserved
    🔄 Git Auto-Sync
    What is Git Auto-Sync?

    COGSPACE can automatically sync your code with GitHub on every wake and sleep cycle. This ensures you never lose work and never work on stale code.

    How it works:
    • First time: COGSPACE detects GitHub remote and prompts you to enable auto-sync
    • On wake (./hi): Auto-pulls latest changes from remote (prevents working on stale code)
    • On sleep (./bye): Auto-commits and pushes all changes (ensures cloud backup)
    Default Behavior (Recommended):
    • Auto-sync is enabled by default (opt-out, not opt-in)
    • Aligns with COGSPACE 90%+ continuity promise
    • Protects against hardware failure and data loss
    Disable auto-sync:
    git config cogspace.autoSync.wake false
    git config cogspace.autoSync.sleep false
    Enable auto-sync:
    git config cogspace.autoSync.wake true
    git config cogspace.autoSync.sleep true
    📖 Git Basics
    What is Git?

    Git is a version control system that tracks changes to your code over time. It allows you to save snapshots of your work, collaborate with others, and recover from mistakes.

    Core Git Concepts:
    • Repository: The folder containing your code and its history
    • Commit: A snapshot of your code at a specific point in time
    • Remote: A copy of your repository hosted on GitHub (cloud backup)
    • Branch: An independent line of development (main branch is default)
    Common Git Commands:
    git status
    See which files have been modified
    git log
    View commit history
    git pull
    Download latest changes from remote
    git add .
    Stage all changed files for commit
    git commit -m "message"
    Create a snapshot with description
    git push
    Upload commits to remote (cloud backup)
    💡 With COGSPACE Auto-Sync:

    You don't need to run these commands manually! COGSPACE handles git operations automatically on wake and sleep cycles, ensuring your work is always backed up and synchronized.
